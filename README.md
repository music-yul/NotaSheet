# NotaSheet · 노타시트

**음악 교사를 위한 악보·활동지 제작 도구**

수업 활동지와 악보를 한 화면에서 만들고, 학생용·교사용으로 나눠 인쇄할 수 있는 웹 앱입니다.
설치 없이 브라우저에서 바로 사용합니다.

> 지금은 **프로토타입(시험 운영) 버전**입니다. 사용 중 불편한 점이나 오류는 아래 [문의](#문의)로 알려 주세요.

---

## 바로 사용하기

1. 브라우저(크롬 · 엣지 · 웨일)에서 NotaSheet 주소를 엽니다.
2. 왼쪽 사이드바에서 넣을 요소(제목 · 표 · 악보 등)를 누릅니다.
3. 다 만들었으면 오른쪽 위 **학생용 인쇄** 또는 **교사용 인쇄**를 누릅니다.
   - 학생용: 정답이 숨겨진 채로 인쇄돼요.
   - 교사용: 정답이 보이는 채로 인쇄돼요.
   - 인쇄 창에서 'PDF로 저장'을 고르면 PDF 파일이 됩니다.
4. 고쳐 쓸 파일이 필요하면 **Word로 저장 ▾**에서 학생용 또는 교사용을 고릅니다.
   - .docx 파일로 내려받아지고, MS Word와 한글에서 열어 고칠 수 있어요.
   - 학생용은 정답이 밑줄 빈칸으로 바뀌어 있어요.

## 주요 기능

### 활동지 만들기
| 기능 | 설명 |
|---|---|
| 글 양식 · 디자인 | 미리 만든 활동지 틀과 색 디자인을 골라 시작 |
| 제목 · 학번 이름 · 글상자 · 답안 공간 | 활동지의 기본 요소 넣기 |
| 정답 지정 | 지정한 글자는 학생용 인쇄에서 숨겨짐 |
| 표 · 이미지 · 도형 · 선 | 표는 행·열과 테두리 모양을 고르고 미리 보기. 칸 경계선을 끌어 열 너비·행 높이 조절 (경계선 더블클릭 = 열 너비 똑같이) |
| Word로 저장 | .docx로 내려받기 (학생용 / 교사용). 한글에서도 열림 |
| 오선 넣기 · 피아노 · 음악 기호 | 빈 오선, 건반 그림, 음악 기호를 글 속에 넣기 |

### 악보 편집기 (사이드바 → 악보제작)
| 서양기보 | 국악기보 |
|---|---|
| 오선보 (대보표 · 화음 · 셈여림 · 반복 기호 · 빠르기말) | 정간보 (세로쓰기 · 가로쓰기, 한 정 최대 9칸) |
| 기타 타브 · 우쿨렐레 타브 (코드명을 쓰면 기본 운지 자동 입력, 코드 운지표 표시) | 장단보 (장구 기호 · 구음, 상자 있음/없음) |
| 드럼 악보 · 단선보(리듬) | 정간보 → 오선보, 장단보 → 리듬보 자동 함께 보기 |

**문제 내기 기능**
- **빈자리:** 음표를 흰 빈칸(테두리 있음/없음)이나 괄호(오선 보이기/가리기)로 바꿔요. 여러 음표를 한 상자로 묶을 수도 있어요.
- **보기 전환:** 정답 보기와 학생용 보기를 바꿔 가며 확인할 수 있어요.

**고치기**
- 악보 위의 기호를 누르면 선택돼요. 선택한 뒤 **Delete**로 지우고, 끌어서 옮기고, **더블클릭**으로 고쳐요.
- 단축키 전체는 편집기에서 **F1**을 누르면 볼 수 있어요.

## 저장과 개인정보

- **자동 저장 위치:** 지금 쓰는 컴퓨터의 **브라우저 안에만** 저장됩니다. 서버로 전송되는 자료나 개인정보는 없습니다.
- **사라질 수 있는 경우:** 브라우저 기록을 지우거나 다른 컴퓨터에서 열면 자료가 보이지 않습니다. 중요한 활동지는 **파일 저장**으로 내려받아 두세요. 내려받은 파일은 **열기**로 다시 불러올 수 있어요.
- **인터넷 연결:** 화면에 쓰이는 글꼴과 PDF 읽기 기능은 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

## 권장 환경

- PC의 크롬, 마이크로소프트 엣지, 네이버 웨일 최신 버전
- 화면 너비 1280px 이상 (태블릿·휴대폰은 보기 위주로 사용)

## 오류가 났을 때

화면 오른쪽 아래에 **"⚠ 오류 · 눌러서 내용 복사"** 버튼이 나타나면, 버튼을 눌러 복사한 내용을 [문의](#문의) 채널로 보내 주세요. 원인을 찾는 데 큰 도움이 됩니다.
