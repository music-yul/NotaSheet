# NotaSheet

음악 교사를 위한 맞춤형 활동지 제작 도구입니다. A4 활동지에 글, 표, 악보, 이미지, 답안 공간 등을 배치할 수 있습니다.

## 사용 방법

`index.html`을 GitHub Pages에 게시하거나 브라우저에서 열어 사용합니다. 외부 편집기·악보 라이브러리를 CDN에서 가져오므로 인터넷 연결이 필요합니다.

## 오픈소스 및 저작권 고지

NotaSheet는 다음 오픈소스를 사용합니다.

| 구성 요소 | 버전 | 라이선스 | 용도 |
| --- | --- | --- | --- |
| [Tiptap](https://github.com/ueberdosis/tiptap) | 3.31.3 | MIT | 글·표 편집 |
| [VexFlow](https://github.com/vexflow/vexflow) | 4.2.6 | MIT | 악보 렌더링 |

원저작권 표시 및 MIT 라이선스 전문은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 수록했습니다. 프로그램 상단의 **오픈소스·라이선스** 버튼에서도 확인할 수 있습니다.

Tiptap의 유료·클라우드 기능은 사용하지 않습니다. 외부 라이브러리의 라이선스는 NotaSheet 자체 소스코드에 대한 이용 허락과 별개입니다. NotaSheet 자체의 공개·재사용 조건은 별도 라이선스를 지정하기 전까지 명시되지 않은 상태입니다. CDN 하위 의존성의 라이선스는 별도 점검이 필요합니다.
